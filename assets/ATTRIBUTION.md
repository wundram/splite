# Attribution

Every external source model used in capture or the game must have an exact
source URL, author, license, downloaded filename and checksum recorded here.
Exact download checksums are stored in the linked source manifests below.

| Id | Origin | Notes |
| --- | --- | --- |
| `tree_hero` fixture | Generated by `tools/pipeline/import/ply_to_cloud.py::make_canopy` in this repository | Procedural canopy, not a Poly Haven model and not a trained fit. |

The former Poly Haven URLs were placeholders, not evidence of asset provenance.
No third-party source-model license is claimed for these repository fixtures.

Portable derivatives live in `assets/models/garden/`. Blender preparation scripts
in `tools/pipeline/blender/` select meshes, repair texture references, recolor
foliage, pose characters and normalize scale. Large downloaded originals and
generated capture/training data are local, ignored inputs; manifests and licenses
remain versioned. The study's island, stepping stones, pond and bridge are authored
in this repository. `assets/models/garden` contains source models;
`assets/clouds/garden/{tree,ranger}.tres` contains genuine trained derivatives
with learned surface normals. Their `*-fit.json` reports record provenance,
training stages, held-out metrics and checksums. Geometry proxies from the source
models provide shadows in the separate fitted study.

The Ranger walk (`assets/clouds/garden/ranger_walk` and matching model proxies)
is a derivative of the same KayKit CC0 Ranger and its `Walking_A` animation from
`Rig_Medium_MovementBasic.glb`. `clip.json` records source/animation/fit hashes;
the bake retains Gaussian correspondence and transfers source rig weights.

Living garden additions: `garden_maple.glb`, `garden_birch.glb`,
`garden_pine.glb`, and `garden_deadwood.glb` come from the same CC0 Quaternius
Ultimate Stylized Nature pack. Adjacent JSON files record the exact source object,
source SHA256 and normalized width. `tools/pipeline/blender/export_more_trees.py`
reproduces these exports. They remain source meshes; no new training is implied.
The living garden's statues, vines/roses, hedges, rabbit/bird/koi forms and spell
geometry are authored procedurally in this repository. UI fonts use Godot
SystemFont fallbacks; no system font files are redistributed.
